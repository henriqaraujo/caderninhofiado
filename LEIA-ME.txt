CADERNINHO DO FIADO - como publicar na Locaweb

1. Entre no Painel da Locaweb > Hospedagem de Sites > Gerenciador de Arquivos (ou use um programa de FTP).
2. Abra a pasta "public_html" (ou a pasta do dominio/subdominio que vai usar).
3. Envie TODO o conteudo desta pasta (nao o .zip), mantendo as pastas: css, js, fonts, icons e os arquivos index.html, sw.js e manifest.webmanifest.
4. Acesse o endereco do site. Se o HTTPS estiver ativo (certificado SSL no painel), o sistema pode ser instalado no celular como aplicativo e funciona sem internet depois da primeira abertura.

Atualizando uma versao nova: envie os arquivos por cima (inclusive js/controles.js, que e novo) e, no arquivo sw.js, aumente o numero em VERSAO (agora esta 'v4'; na proxima troque para 'v5'). O sistema sempre busca a versao mais nova quando ha internet.

Os dados de cada comerciante ficam no proprio navegador/aparelho dele. Nada e gravado na Locaweb. Por isso a cobranca de "Copia de seguranca" em Ajustes e importante.


ACESSO (LOGIN) E ADMINISTRAÇÃO
- O sistema agora pede usuário e senha (PHP). Abrir o index.html direto do computador não funciona mais.
- No primeiro acesso, abra o endereço do site: aparece "Primeiro acesso" para criar o administrador. Faça isso logo após publicar.
- Administração (menu "Mais" ou lado esquerdo): criar usuários, trocar senha, desativar, tornar admin, excluir.
- Os usuários ficam na pasta _dados_caderninho (criada automaticamente ao lado da pasta do sistema, em public_html). Ela precisa de permissão de escrita.
- O login só controla quem entra. Os dados dos fiados continuam salvos no navegador de cada aparelho.


BANCO DE DADOS (MySQL da Locaweb)
- Os dados de cada comércio ficam no banco. Todos os usuários do comércio veem o mesmo caderninho, em qualquer aparelho.
- A conexão é configurada uma vez em Administração > Banco de dados (endereço, nome do banco, usuário e senha). Esses dados ficam só na pasta protegida _dados_caderninho/banco.php e NUNCA vão para o GitHub.
- Ao conectar, as tabelas são criadas e os usuários antigos são trazidos para o banco automaticamente.
- Cada usuário novo criado pelo admin vira um comércio (com os dias de teste). O dono pode adicionar até 5 pessoas em "Minha equipe". O período de teste vale para o comércio todo.
- O caderninho que já estava no navegador de um usuário é enviado ao servidor no primeiro acesso depois da atualização.
- Cópia diária automática no próprio banco (tabela dados_bkp, últimos 14 dias).
